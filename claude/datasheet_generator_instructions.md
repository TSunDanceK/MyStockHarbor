# Investor Datasheet Generator — Instructions (mirror)

This is a GitHub mirror-summary of the `datasheet_generator_instructions.md`
doc kept in the Claude Project "My Stock Harbor Website" (root-level doc
there, mirrored here under claude/ for consistency). It's the full HTML
template + step-by-step process for generating a 16:9 investor-datasheet PNG
image for a given ticker (used for YouTube/social visuals), including the
required `bg.png`/`logo.png` assets, the fixed 8-row data schema, and the
wkhtmltoimage render command. Read the Claude Project copy for the complete
template and instructions — it's long-form HTML/CSS and is kept there as the
actively-edited source.
